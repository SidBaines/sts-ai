# Reusing public encodings across rollout and PPO

The actor previously encoded each public observation for action sampling, then PPO preparation encoded the same retained observations again. Each immutable rollout transition now retains the exact in-memory encoding used by the standard actor collator. The update collator reuses it after checking the original observation object's identity and legal-menu indices. Generic/custom collators retain their original path. `reuse_encodings=False` remains available for controlled comparisons.

This cache belongs to the current transition buffer, not to a global dictionary. Faulted trajectories and their encodings are discarded together. Encodings are not added to public observations, checkpoint metadata or JSONL schemas; the training CLI discards transition objects before serializing metrics. Bootstrap, action ordering, rewards, GAE, RNG draws and model updates are unchanged. Count/byte diagnostics report retained encodings and PPO reuse.

A bounded CPU comparison used 2,048 public development observations from the corrected-native Act-1 teacher bank across 11 dev worlds. It never executed a policy on final worlds. Across five preparations, median re-encoding took 0.3882 seconds and reuse/validation took 0.001078 seconds: approximately 360x faster preparation on this fixture. This is preparation speed, not an end-to-end training speed claim. Existing live chunk timing identified preparation as roughly 39–40 seconds per 180-second chunk, so the next completed chunk must confirm actual wall-time benefit.

The fixture averages 3.90 legal actions. State/action/index NumPy payload is 6,255,072 bytes for 2,048 observations; arrays, encoding objects and coverage-dictionary allocation estimate is 7,631,328 bytes. At 20,000 retained transitions the projected numeric payload is about 61.1 MB (decimal), with further object/cache overhead. The cache lifetime ends when the buffer/update closure is released; no array compression or lower precision is used.

CPU validation includes deterministic and stochastic action/log-prob/value/GAE parity, whole-fault-episode quarantine, exact public feature arrays and padded tensors, unchanged custom collators, and fail-closed mismatched observation/menu tests. A real 128-dev-observation PPO comparison accepted eight updates in both paths and produced bit-identical losses, gradients, Adam state and resulting weights. Its preparation fell from 0.01982 to 0.000150 seconds. Five dedicated tests plus 28 related training/composite/KL/fault tests passed before activation.

Measured values and fixture worlds are preserved in [nonllm_encoding_reuse_evidence.json](nonllm_encoding_reuse_evidence.json). The microbenchmark ran CPU only while the parent retained exclusive GPU ownership; scientific settings were not changed.
