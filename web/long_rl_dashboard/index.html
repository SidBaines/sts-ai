Fixed settings and measurement limits

Job throughput uses measured job elapsed time; rollout throughput excludes optimizer time. Losses are arithmetic means of logged update summaries within each job. Returns include non-faulted episodes, including any truncated episodes. No gradient norm is inferred from the configured clipping threshold.
